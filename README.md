# GenShell
A dedicated shell for GenTools

## Supported Tools
- ReGen: An automated pipeline that ingests documents or web pages, extracts structured data using LLMs, analyzes cross-source patterns, and generates polished reports rendered with Quarto.
- DocuGen: CLI that generates high-quality docstrings for Python code using an LLM, inserted with AST-aware rewriting that preserves the rest of your file byte-for-byte
